# Evently
Individual assessment in HTML and CSS for the frontend education with Lexicon.

## :white_check_mark: Assessment Criteria
- [x] The design faithfully follows the reference images (below).
- [x] The website is responsive from page width ca 300px up to ca 1920px.
- [x] Forms, semantics and navigation are accessible and tested with WAVE and Lighthouse.
- [x] Code is clean and structured with appropriate class naming.
- [x] Only HTML and CSS, no libraries like React, Bootstrap or Tailwind are used.
- [x] Any code obtained from other sources is clearly referenced.

## :star: Bonus Features
- [ ] Heart/favorite button on cards (implemented in branch ["after-deadline"](https://github.com/josiefinis/Evently-2026/tree/after-deadline))
- [x] Varied colors for card tags
- [x] Working hamburger menu
- [x] Light and dark themes with `dark-light`

## :eye: Demo
[Visit page](https://josiefinis.github.io/Evently-2026/)

## :wheel: Under the hood
- Semantic HTML5
- Modern CSS following CUBE naming convention
- Flex and Grid layouts
- Media och container queries
- oklch color system
- CSS `translate` function for the hamburger menu

## :sewing_needle: Technologies
- HTML5
- CSS3
- WAVE
- Lighthouse

## :bug: Known Issues
The main branch contains the version as it was at the deadline and contains some issues,
- Card images have two alt texts defined. WAVE at least sees the correct one.
- The headings *Hitta rätt evenemang* and *Populära Evenemang* become too small for small screen widths.
- The hero image layout is not completely faithful to the reference for tablets.
